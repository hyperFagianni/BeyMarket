----------------------------------------------------
API ADMIN – ENDPOINT DISPONIBILI
----------------------------------------------------
Tutte le route richiedono header:
  Authorization: Bearer <token_admin>

  GET    /admin/users                  Lista tutti gli utenti
  PUT    /admin/users/:id/role         Cambia ruolo utente
                                       body: { "role": "admin" | "user" }

  GET    /admin/listings               Lista tutti gli annunci
  DELETE /admin/listings/:id           Elimina un annuncio

  GET    /admin/orders                 Lista tutti gli ordini
  POST   /admin/orders/:id/refund      Forza rimborso acquirente
                                       (riaccredita escrow_amount)

  GET    /admin/messages               Lista conversazioni (coppie utenti)
  GET    /admin/messages/:uid1/:uid2   Leggi chat tra due utenti


----------------------------------------------------
PASSI DA SEGUIRE PER METTERE IN FUNZIONE
----------------------------------------------------

PASSO 1 – Assicurati che il backend sia stato avviato
          almeno una volta DOPO queste modifiche,
          in modo che la migrazione aggiunga la colonna
          "role" al database esistente.

  cd backend
  npm start

  (poi puoi fermarlo con CTRL+C)


PASSO 2 – Crea il tuo utente admin

  Dalla cartella backend, esegui:

    node scripts/create-admin.js admin@beymarket.it LatuaPassword99!

  Oppure senza password nel comando (la chiede in modo sicuro):

    node scripts/create-admin.js admin@beymarket.it

  Lo script:
  - Se l'email NON esiste → crea un nuovo utente con ruolo admin
  - Se l'email ESISTE già → aggiorna la password e promuove a admin

  ATTENZIONE: usa una password sicura (minimo 8 caratteri).


PASSO 3 – Avvia il backend

  cd backend
  npm start

  Il backend sarà in ascolto su http://localhost:3000


PASSO 4 – Apri il pannello admin nel browser

  Apri il file:
    pages/admin.html

  Oppure, se stai servendo i file statici, vai su:
    http://localhost:<porta>/pages/admin.html

  Inserisci email e password dell'admin creato al Passo 2.


PASSO 5 – Funzionalità disponibili nel pannello

  TAB UTENTI:
  - Vedi tutti gli utenti registrati con saldo e ruolo
  - Pulsante "Promuovi admin" → assegna ruolo admin
  - Pulsante "Revoca admin"   → torna a ruolo user

  TAB ANNUNCI:
  - Vedi tutti gli annunci con venditore e prezzo
  - Pulsante "Elimina" → rimuove definitivamente l'annuncio

  TAB ORDINI:
  - Vedi tutti gli ordini con stato e importo in escrow
  - Pulsante "Rimborsa" → riaccredita l'importo all'acquirente
    e imposta l'ordine su 'cancelled'
    (visibile solo se c'è ancora importo in escrow)

  TAB MESSAGGI:
  - Vedi l'elenco delle conversazioni tra utenti
  - Pulsante "Leggi" → mostra i messaggi della chat
    (utile per gestire segnalazioni)


----------------------------------------------------
NOTE TECNICHE
----------------------------------------------------

- Il ruolo admin è controllato lato backend ad ogni
  richiesta: anche se qualcuno modificasse il token,
  il middleware verifica il ruolo direttamente dal
  database.

- Le route /admin/* NON sono accessibili senza un
  token JWT valido con ruolo 'admin'. Un utente
  normale riceve errore 403.

- La tabella "messages" è stata aggiunta per supportare
  la futura messaggistica tra utenti. Attualmente il
  pannello admin può già leggerla; manca ancora il
  backend completo della messaggistica (vedi ideas.txt).

- Il pannello admin (pages/admin.html) è un file HTML
  statico: non va su internet, comunicando direttamente
  con localhost:3000. Tienilo accessibile solo agli
  amministratori del sito.
